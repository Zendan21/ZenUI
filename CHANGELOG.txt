ZenUI 1.0.25 - ZenStylingPack integration

- Appearance can operate in Global mode through the standalone EbonAPI shared store or Local mode for ZenUI only. EbonAPI remains optional and is not bundled.

- Keeps ZenUI's existing mover/layout/component-scale systems independent from the shared style.

- Existing 1.0.24 Classic/Obsidian/Glass choices migrate into the equivalent ZenStylingPack style; old Dark Mode profiles continue to map to Obsidian.
- Database schema is now 47 for styling mode/style migration.
